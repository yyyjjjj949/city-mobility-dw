# 离线核心指标口径

当前版：2026-11-03。历史范围2025年6月，以纽约当地开始日期统计；分层事实记录UTC瞬时值、当地时间和源时间文本。

| 指标 | 定义 | 范围和限制 |
| --- | --- | --- |
| 有效行程量 | 通过核心时间、时长和身份规则的行程数 | 出租车和骑行分别统计，再按共同粒度比较 |
| 骑行量 | 有效且无内容冲突的ride_id数 | 同ID同业务内容去重，同ID冲突阻断发布 |
| 平均时长 | 有效时长总和 / 有效时长记录数 | 不平均每日平均值；看板以分钟展示 |
| 出租车平均距离 | 距离合格记录的公里总和 / 合格记录数 | 英里乘1.609344；骑行源无真实行驶距离 |
| 区域出发量 | 在完整来源范围内，从对应纽约区域出发的行程数 | 未匹配区域不纳入区域指标，保留原行程 |
| 六月出发队列OD | 六月开始且起终区域均匹配的行程数 | 不等同于按六月到达时刻统计的完整到达量 |
| 完整到达量 / 净流入 | 事件到达窗口内的到达量 / 到达减出发 | 缺少五月边界源时保持NULL，不填零 |
| 小时日均出发量 | 纽约当地某小时的六月总量 / 30天 | 首版六月无夏令时切换；后续月份需单独处理重复小时 |
| 天气需求比率 | 该天气组完整日均量 / 同月同方式同周类型基准日均量 | 基准为无可测降水；零分母或无样本返回NULL |
| 质量有效率 | 接收记录数 / 解析成功输入数 | 同时展示隔离、重复跳过、范围外和解析失败 |
| 区域匹配率 | 起点/终点/双端成功匹配数 / 对应全部有效行程数 | 三种覆盖率分别展示 |

天气微量降水单独分组，缺失天气不填晴天。周一至周五与周末分别比较；未接入节假日日历时is_holiday保持NULL。相关性不能解释为因果。

指标由DWS/ADS统一计算，Superset读取已校验发布视图。站点维度用于历史骑行起终点分析，不提供当前库存、缺车时长或实时运营预警。
