# 离线数据范围与来源清单

当前范围于2026-11-03确认：以2025年6月为首版完整月，分析纽约Yellow Taxi、Citi Bike骑行、NOAA中央公园日天气、官方区域编码和空间边界。历史数据用于离线批量分析，真实来源和下载校验记录保留。

| 来源 | 内容 | 加工与使用 |
| --- | --- | --- |
| NYC TLC官方行程文件 | 行程起终时间、区域、距离及费用 | 清洗为出租车行程事实 |
| Citi Bike官方月度骑行文件 | ride_id、起终站点、时间、坐标、车型、会员类型 | 清洗为骑行事实和历史站点维度 |
| NOAA/NCEI中央公园日天气 | 温度、降水、风速及质量标志 | 按纽约当地日期关联历史日行程 |
| NYC Taxi Zones | 区域编号、名称、行政区及边界 | 区域维度、坐标匹配和空间分析 |

来源详情见 `data-source-catalog.json`、`sample-manifest.json` 与原始归档对象清单。样例在 `data/samples`，完整源文件在 `data/ods/files`，ODS记录在 `data/ods/source_record`。历史采集不要求实时接口。

七、八月文件曾核验可用，当前尚未纳入正式指标。单月满足首版完整月分析；扩展月份必须同时处理时区、日期骨架、维度期间与图表范围。

源时间统一明确为America/New_York，保存UTC瞬时值和原文本。夏令时歧义/不存在时刻需检查，不按服务器当前日期推断历史业务分区。天气为日级观测，不冒充小时天气。

未采集五月边界源，完整六月事件到达量和净流入不发布。空间未匹配的有效行程可参与时间趋势，区域与OD使用各自匹配条件。总量只代表已接入的两类行程。
