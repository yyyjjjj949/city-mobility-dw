更新日期：2026-11-14。验收数据以outputs中的JSON记录为准；短时连续探测与重启测试不等同于多日无人值守运行。

## 地图和筛选

项目首页“地图与联动筛选”打开 `outputs/map/map.html`，无需服务或外网。启动项目后也可打开 http://localhost:8088/city-mobility/map/ ，区域与OD看板提供同一入口。

地图使用D3 7.9.0和本地NYC TLC官方WGS84区域边界，包含262个纽约区域；图形颜色表示绝对出发量，不是人口/面积密度。未映射到纽约区域的起点不着色，计入全局行程分母，单独显示未映射量。完整月地图出发量9,001,765条，有效行程9,012,795条，未映射起点11,030条。

日期、交通方式、行政区、区域筛选会联动地图、前15排行、日趋势及当前区域出发量；“同期已接入有效行程”和纽约起点覆盖率仅随日期及交通方式变化。结束日期包含当天。鼠标点击、键盘Enter/空格或区域下拉框均可选区；点击已选区域可取消。缩放按钮不抢占页面滚轮。导出CSV包含当前全部区域的出发量，包含0量行；排行只列有出发量的前15个区域。

筛选保存在URL hash；复制地址、刷新及浏览器前进后退可恢复。非法地址会提示并恢复六月默认范围，非法表单不替换现有结果。地图没有可用记录时显示空结果，不能把未知值伪装成0。页面有移动端布局，数据和依赖保存在D盘；导出来自某次已校验的发布快照，页面明确显示生成时间及发布版本。

Superset历史总览与区域OD新增原生日期范围和交通方式筛选；区域看板的行政区筛选仅影响两张区域图，OD和全局覆盖率不受行政区筛选影响。天气看板支持交通方式筛选。质量看板不混用行程日期筛选。Superset日期范围的结束时刻不包含在内，例如查看6月1—7日应设置开始2025-06-01、结束2025-06-08。小时日均分母随选中日期变化；固定方式KPI与方式筛选取交集，无对应数据时可能显示0/无结果，这是空交集而非查询故障。

## 完整月度流程

Airflow DAG `city_mobility_historical_daily` 每天北京时间02:00运行；也可双击 `运行完整离线流程.cmd` 或在Airflow触发并填写 `{"month":"2025-06"}`。首版仅支持已验证的2025年6月，其他月份明确拒绝，不能将参数入口理解为已支持任意月份。

```text
ingest_ods → verify_ods → build_dwd → verify_dwd → build_marts
  → register_dashboards → verify_charts → export_map → export_preview → inspect_project
```

采集入口校验完整本地源文件SHA；文件已存在且元信息一致时不依赖外网，不重复下载。`--reuse-verified`仅在来源SHA、来源集合、验收月份和已验证Delta月分区文件完全一致时复用ODS，否则执行正常入仓。DWD使用固定ODS快照；新验收版本仅包含元数据或其他来源变化时，经月分区文件对照后保留旧版本。DWD输入来源、规则、映射、加工代码、契约及维度/事实版本一致才复用。共享OPS审计表新增记录不导致无意义的全量DWD重建。

DWD独立验收读取准确的提交快照，检查Parquet行数、全部行程时长与UTC时间差及抽样ODS追溯。DWS/ADS使用新的已验证DWD版本构建，ClickHouse逐表全量校验后才原子切换historical/quality两个发布指针。来源变化或加工规则改变会重算；每一步失败阻断后续任务，原发布继续提供查询。

Airflow每步失败重试一次，间隔一分钟；单DAG单运行、任务串行。本机执行器只接受固定动作和允许的month参数，拒绝额外字段、命令文本及非法月份。Spark忙时调度中的DWD/指标步骤等待资源；手工命令仍立即拒绝并发。每步等待包含在45分钟请求期限内，任务最大47分钟。机器关机/休眠不运行任务，catchup=False不补齐停机期间的全部计划；恢复后可手动重跑目标月。

## 验收证据

- `map-build-verification.json`：地图与发布数据总量、262个区域、发布快照和SHA。
- `map-browser-verification.json`：组合筛选对照ClickHouse、CSV、日期校验、URL、键盘、缩放及移动端。
- `native-filter-browser-verification.json`：Superset原生筛选实际交互。
- `airflow-verification.json`：真实Airflow完整任务链和监控DAG。
- `pipeline-failure-verification.json`：非法月份入口失败，9个下游任务未执行，发布指针不变。
- `stability-soak-verification.json`：有实际开始时间、采样数和持续时长的连续HTTP/发布总量探测。
- `restart-verification.json`：服务和执行器重启后的账号、图表、发布版本与数据计数。
- `pipeline-replay-verification.json`：第二次完整DAG及三层复用回执，业务Delta版本、DWD构建ID和发布指针保持不变。
- `offline-verification.json`：以上结果的综合验收。

所有JSON在项目outputs下，截图包括map-desktop、map-filtered、map-mobile及superset-native-filter。失败记录保留在Airflow及work/orchestration中，不删除历史失败来美化验收。最新成功结果用于判断当前是否恢复。

验收期间修复了两处实际故障：ClickHouse批量导入关闭并行解析、限制插入线程及块大小，避免本机内存上限；执行器对Windows读者短暂持有状态文件时的原子替换增加有限重试，心跳遇短暂共享冲突会继续下一轮。后者有模拟共享冲突后恢复的回归测试。Superset图表显式指定日期列，避免日期范围仅出现在控件中而未进入查询。
