## 1. 实际实现的爬取过程

| 来源 | 实际访问与解析 | 发现结果 |
| --- | --- | --- |
| NYC TLC出租车 | 请求官方历史数据网页，使用Python标准库HTMLParser提取`a[href]`，按`yellow_tripdata_YYYY-MM.parquet`精确匹配 | 目标月份出租车Parquet链接 |

两个主要业务数据源已经增加“请求官方网页/目录—解析内容—筛选目标月份—验证对象身份—下载—ODS入仓”的实际代码。爬虫负责发现公开数据对象，文件下载器负责传输与校验，两者职责不同。真实业务内容仍来自原官方文件，不伪造行程，也不逐条抓取不存在的网页行程详情。

## 2. 使用方式

在项目根目录执行，需Python环境安装已有的requests、pyarrow依赖：

```powershell
# 实际爬取两类官方来源并保存证据，不下载大型行程文件、不写ODS
python tools/ingest_sources.py --month 2025-06 --discover-only

# 只爬取Citi Bike来源
python tools/discover_sources.py --month 2025-06 --source citibike

# 两类来源都爬取
python tools/discover_sources.py --month 2025-06 --source all

# 本地数据存在时仍强制先做在线发现，然后进入原采集流程
python tools/ingest_sources.py --month 2025-06 --crawl-first --reuse-verified
```

也可双击项目根目录的`爬取官方数据目录.cmd`，仅执行目录爬取。

默认输出位于本聊天独立目录：

- 爬取回执：`outputs/2026-11-18-theme-definition-e721eb90/crawl/`。
- 原始响应和请求日志：`work/2026-11-18-theme-definition-e721eb90/source-discovery/<run-id>/`。
- 单独运行`discover_sources.py`可通过`--work-dir`和`--output-dir`指定D盘其他本次任务目录。

程序保存请求地址、UTC访问时间、HTTP状态、内容类型、响应字节数、SHA-256、解析方法、发现的对象链接与目录匹配结果。原始响应使用序号文件保存，回执能追溯到对应run目录。公开仓库保留脱敏回执，原始网页响应留在本地work，不将第三方整页内容作为自己的文档发布。

## 3. 与离线数仓的关系

“离线数仓”指按历史批次加工，不等于禁止联网采集。在线爬取发生在数据获取阶段，ODS之后继续采用历史批处理。

- **新文件首次获取**：如果主业务源文件缺失，先执行对应来源的在线发现；发现失败则停止，不静默退回硬编码链接。
- **既有完整文件重跑**：不强制联网；继续核对下载sidecar中的来源URL、大小及完整SHA-256，通过后复用，便于离线演示和稳定复跑。
- **主动演示爬取**：使用`--discover-only`，能展示真实解析，不重复下载约929MB的骑行ZIP。
- **显式更新发现**：使用`--crawl-first`。如果官网结构改变、robots策略拒绝、HTTP访问失败或结果与目录不同，任务失败并留回执，须人工检查，不能自动换源。

发现的URL必须与已验证来源清单精确一致；Citi Bike对象大小还须与清单一致。文件大小匹配不是内容校验的替代，实际下载仍计算完整SHA-256，并执行已有格式/ZIP校验。

## 4. 访问约束与失败行为

- 仅允许预先登记的官方HTTPS主机，拒绝URL内嵌用户名/密码、非HTTPS链接及非443端口。
- 逐个检查robots.txt：200时解析规则，404/410视为无规则；其他状态或获取失败按失败处理。禁止规则会阻断目标请求。
- 请求串行，最小请求间隔0.6秒；连接/读取超时分别10/25秒，单请求最多两次尝试。
- XML列表最多10页，检查分页token重复；单响应上限8MiB，拒绝XML的DTD及实体声明。
- 最多三次重定向，每个目标重新校验主机和robots规则；不跟随外站重定向。
- 网络异常只记录异常类别，避免在日志中泄露可能含认证信息的代理URL；程序不改变系统或Docker代理设置。

## 6. 报告中的准确表述

> 本项目通过Python爬取TLC官方历史数据网页及Citi Bike官方数据页面，解析月份文件链接，并读取其公开对象目录定位目标月份文件。经来源身份核对后，采集模块下载官方文件，完成校验、来源登记和ODS入仓。天气采用官方API采集，空间基础数据采用官方文件下载。已验证文件可在无外网条件下复用并进行后续离线批处理。

本实现不宣称所有数据均由HTML爬虫获取，也不把固定URL下载、API请求与网页解析混为同一种方法。
