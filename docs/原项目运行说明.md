# 城市出行数仓系统的设计与实现

当前版本：**离线数仓（2026-11-14验收更新）**。以纽约2025年6月真实数据完成历史采集、清洗、四层建模、主题指标、地图筛选和全链路调度。项目总入口：`outputs/项目总入口.html`；当前需求：`docs/00-离线数仓需求与验收范围.md`。

## 打开与运行

1. 双击 `启动项目.cmd`，启动本机五个服务及Airflow本机执行器。
2. 打开 `outputs/项目总入口.html`，或双击 `打开历史看板.cmd`。Superset：http://localhost:8088 。
3. 调度中心：http://localhost:18080 ，也可双击 `打开调度中心.cmd`。
4. 账号见 `outputs/local-credentials.md`；不要上传凭据。CSV无需启动服务即可用Excel/WPS查看。
5. `检查运行状态.cmd` 检查服务、历史发布、数据总量和本机执行器；不用时双击 `停止项目.cmd`，保留数据。

## 离线数据链路

官方历史文件 → Python批量采集 → ODS原始存储 → Spark DWD清洗与维度关联 → DWS主题汇总 → ADS指标 → ClickHouse校验发布 → Superset历史分析。

源数据覆盖Yellow Taxi、Citi Bike骑行、NOAA日天气和出租车区域。六月原始行程9,082,305条，得到9,012,795条有效行程：出租车4,254,337条、骑行4,758,458条；68,604条隔离，906条范围外。总量不能解释为全市全部出行量。

当前模型为7个维度、两张行程事实表，历史汇总为5张DWS和7张ADS；本地操作入口提供四个看板、19张图表及五份小规模CSV导出。各层结果和质量记录均保留来源和版本。

| 操作 | 入口 | 说明 |
| --- | --- | --- |
| 历史采集与ODS | `采集六月数据.cmd` | 按来源月份下载/复用、校验、入仓 |
| DWD清洗 | `清洗六月数据.cmd` | 七个维度、两类行程清洗、质量隔离 |
| 历史指标与看板 | `构建历史指标.cmd` | 构建/复用DWS与ADS、校验图表、导出CSV |
| 地图与筛选 | `outputs/map/map.html` | 日期、方式、行政区、区域联动，筛选CSV导出 |
| 完整调度与监控 | `运行完整离线流程.cmd`、`打开调度中心.cmd`、`检查运行状态.cmd` | 十步链路每天北京时间02:00更新/复用，状态每5分钟检查 |

Airflow 已串联采集、ODS验收、DWD加工与验收、指标构建、看板检查、地图导出和项目检查共10步；每天北京时间02:00运行，也可通过 `运行完整离线流程.cmd` 手动触发。当前只允许已验收的2025年6月，其他月份会被入口拒绝。
