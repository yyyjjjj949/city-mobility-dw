出租车有效行程4,254,337条，骑行4,758,458条；合计只表示已接入的两类有效行程，不代表全市总出行量。总量包含时间有效但空间未匹配的记录，区域与OD按各自空间条件计数。

区域小时表补齐262个纽约区域 × 720小时 × 2类方式的出发量，零值表示完整采集范围内无对应出发行程。由于尚未采集五月边界源，完整事件到达量及净流入均保持NULL，arrival_complete=false；OD仅表示六月开始的行程。

平均时长、距离采用有效分子总和÷有效分母总和；不平均每日平均值。当地小时图为每小时月度出发总量÷30天。天气采用NOAA中央公园日天气，将微量降水单列，按方式、周一至周五/周末分别比较日均出行量，展示样本天数。需求比率基准为同月同组无可测降水日；比较不表示因果。

## 构建、发布与恢复

双击 `构建历史指标.cmd`，依次构建/复用指标、更新看板、验证图表查询、导出CSV。也可在项目目录分别执行：

```powershell
python tools/build_marts.py
python tools/build_dashboards.py
python tools/verify_dashboards.py
python tools/export_marts_preview.py
```

构建清单记录已验证DWD的准确Delta版本、DWD构建ID、规则、模式与代码SHA-256。相同输入复用已发布结果，并核对当前指针与各表行数；数据表版本保持不变。当前首版小时骨架限定2025年6月，不接受其他月份。

DWS按目标月原子替换。ADS候选记录带release_id，候选与旧发布可并存。ClickHouse发布先校验全部7表行数、逻辑键唯一性和每条完整记录的规范化SHA-256多重集，再原子交换发布指针；切换后核对BI视图行数，异常则回退指针。双精度值以12位有效数字规范化进行跨引擎比较。Superset只读 `ads.bi_*` 视图，通过发布指针隔离候选数据。

若指标已校验但发布中断，可运行 `python tools/build_marts.py --resume-release <release_id>`，仅允许输入与构建代码指纹一致的候选恢复；不需要重算Spark。发布后记录ops.publication的历史/质量两个数据集版本，保留输入与发布时间。看板脚本采用固定UUID/slug，可重复执行并保留图表和看板ID。
